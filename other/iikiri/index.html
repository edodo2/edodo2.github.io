言い切り君

2つのどちらにしようか迷っていませんか？
文字列を入力すると、言い切り君が絶対に1つを力強くと言い切ります！

『 {{ resultText }} 』！！
（ハッシュ: A={{ hashA }}, B={{ hashB }} / 差={{ diff }} [{{ isEven ? '偶数→大きい方' : '奇数→小さい方' }}]）
結果をツイートする
言い切り君のルール

2つの文字列を固定ハッシュで数値化し、その差が偶数のときは値の大きい方、奇数のときは値の小さい方を採用します。同じ組み合わせであれば常に同じ結果が選ばれます。
